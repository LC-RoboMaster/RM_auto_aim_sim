# v0.2 架构补充

旋转目标、碰撞统计、校准相机和 RMUC 合成的最新模块职责见
[ARMOR_LAB.md](ARMOR_LAB.md#5-模块与扩展)。以下是基础架构说明。

# 架构与开发约定

## 模块

| 文件/模块 | 职责 |
|---|---|
| `config_fields.def` / `Config` | 一份参数定义，驱动 YAML 加载和 ROS 参数声明；拒绝拼写错误、非法数值 |
| `Engine` | 模型编译、对象名称绑定、手动平移、角度伺服、统一物理步进 |
| `CommandMailbox` | 线程安全的最新命令缓存；控制模式隔离、有限值过滤和可选超时 |
| `ProjectilePool` | 固定槽位复用、发射初始化、首次接触事件、寿命管理 |
| `CameraRenderer` | 独立 MuJoCo 场景/FBO、HDR Shader、GPU 翻转、三槽异步 PBO、针孔内参 |
| `SensorWorker` | 隐藏 GLFW 上下文、模型/数据快照、采集/收帧调度、FPS 与进程负载 |
| `RosBridge` | ROS2 参数、DDS pub/sub、仿真时钟、TF 和消息编码 |
| `viewer_hooks` | 官方菜单扩展、键盘/鼠标控制、第一人称操作 |
| `main.cpp` | 模块生命周期、viewer 主线程、物理线程与快照锁 |

## 线程与所有权

主线程持有 viewer 窗口并运行官方 `RenderLoop`。物理线程在同一个 `Simulate::mtx` 下修改 `Engine` 的 mjModel/mjData；菜单和鼠标回调也在该锁下运行。ROS executor 只操作 `CommandMailbox`，从不直接操作 MuJoCo 数据。

相机线程有自己的一份 mjModel/mjData。每次采样只在短锁内执行 `mj_copyData` 并取得状态时间，然后在锁外渲染和发布。viewer 修改物理选项不改变相机线程自己的模型；相机尺寸/视场角属于启动配置。窗口创建/销毁在主线程，OpenGL 上下文在相机线程使用，FBO 也在该线程释放。

异步采集与收帧分开：新仿真时刻调用 `RenderAsync`，暂停期间调用
`CollectReady` 收取已有 GPU 作业，不产生重复图像。每槽保留自己的时间戳与 K。
新采集时间小于上次采集时间时，在收取任何旧结果前清空待发布队列；删除 fence
不等待 GPU，PBO 的后续写入仍由同一个 GL 上下文排序。性能统计按墙钟更新，
不依赖仿真时间前进。同步 `Render` 保留用于基准成像检查。

状态消息在物理锁内形成快照，DDS 发布在锁外进行。ROS executor 在线程退出后销毁，早于命令缓存销毁。相机线程退出后才销毁其窗口、数据与模型。

## 每个物理步

1. 检测 viewer reset/回退；清除弹丸与旧命令。
2. 读取当前模式：手动输入更新底座与目标角度；自动模式读取最新 ROS 命令。
3. 角度限幅、限速；更新云台运动学姿态。
4. 回收超时弹丸并重置非活动槽位；计算当前枪口世界位姿。
5. 按仿真时间调度发射，用枪口 +x 初始化 22 m/s 速度。
6. `mj_step` 求解重力/接触，记录活动弹丸的首次接触。
7. 重新固定理想云台角度并 `mj_forward`，保证 TF/相机位姿对应步末时间。

底座不是实体底盘；yaw/pitch 为理想限速位置伺服，物理步后的姿态不会被重力或弹丸影响。若后续需要电机动态，替换 `ApplyGimbalPose` 与角度更新为 actuator 控制，同时调整 JointState 的角速度来源。

## 代码规范

- C++17，命名空间 `rm_auto_aim_sim`，Google 风格，2 空格缩进。
- 类型、函数使用 `PascalCase`，普通变量/参数使用 `snake_case`，成员使用 `_` 后缀。
- 常量/枚举使用 `kName`，单位在配置和接口文档中明确。
- 每个类只负责一个模块；避免在官方 viewer 中直接实现 ROS 或弹道逻辑。
- 官方 viewer 只保留少量调用钩子，第三方文件保持其原有格式和版权声明。云台的 WASDQE、方向键和 F 在三维区域内优先于原生渲染快捷键，避免移动时切换 wireframe 或隐去静态物体。

## 后续扩展位置

增加旋转装甲板：在 arena/worldbody 下 include 一个目标 XML，在 `Engine::Step` 中的目标模块更新关节或 mocap，保持同一个物理锁。目标碰撞 geom 命名应稳定；根据 `HitEvent.geom_name` 区分装甲、车体、墙和地面。当前记录的是第一次实际接触，不含比赛得分、装甲判定、阵营与靶标 ID 映射。

增加传感器：让相机线程复用快照，将传感器模块与 `RosBridge` 的消息转换分开。增加模型关节：扩展模型绑定和 TF 结构；不要直接依赖 MuJoCo 的裸数字索引。

原生 viewer 的历史回放只存储 MuJoCo 状态，不存储对象池的生命周期/命令元数据。回退会清空弹丸状态；这不是可复现完整火控事件的录制回放系统。后续可另行实现完整 episode 记录。
